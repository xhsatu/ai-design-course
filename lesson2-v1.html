机制

Skill
是怎么被调用的？

Claude 扫描所有 Skill 的 description
→ 关键词匹配 → 自动激活

大概率不会自动触发——
每个人的业务不同，关键词不一样，
第一次很难一次写对。

没触发？
手动 /skill 名称 调用，
再回来改 description。

装再多 Skill 也不会卡——
只有用到的才会被加载。
重点：自动激活失败是正常的，不是你做错了

现在

把刚才的分析
固化成 Skill

⚠ description 是关键——
关键词决定了它能不能被自动触发。
「把我刚才分析的设计语言
整理成一个 SKILL.md——
· name：用项目名
· description：当用户提到 [你的关键词 A]、
[关键词 B]、或用 [项目名] 风格设计时，自动激活
· 正文：刚才总结的色彩、间距、命名规律

保存到 ~/.claude/skills/[项目名]/SKILL.md。」
